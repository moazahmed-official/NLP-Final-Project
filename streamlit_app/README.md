# استخراج المهارات وتلخيص أوصاف الوظائف — واجهة Streamlit

هذا المشروع يوفر واجهة ويب تفاعلية مبنية بـ Streamlit لتحليل أوصاف الوظائف: من تحميل البيانات، تطبيق المعالجة المسبقة، استخراج المهارات، توليد الملخصات، وصولًا إلى التصور وتنزيل النتائج.

## مكونات المشروع

- `app.py`: الصفحة الرئيسية، تحميل الملف، وإدارة الحالة
- `pages/`: صفحات التطبيق (نظرة عامة، معالجة، استخراج، تلخيص، تصور)
- `src/`: وحدات المعالجة الأساسية (`preprocess.py`, `skill_extractor.py`, `summarizer.py`, `viz.py`)
- `data/jobs.csv`: مثال لملف بيانات
- `output/`: يتم حفظ النتائج هنا عند الطلب

## تشغيل التطبيق

1. إنشاء بيئة افتراضية وتفعيلها

```powershell
python -m venv venv
venv\Scripts\activate
```

2. تثبيت المتطلبات

```powershell
pip install -r requirements.txt
pip install streamlit
```

3. تشغيل التطبيق

```powershell
cd streamlit_app
streamlit run app.py
```

## شرح الواجهة

- الصفحة الرئيسية: رفع ملف CSV (الحقل المطلوب: `id`, `Job Title`, `Job Description`) ومعاينة سريعة.
- صفحة 1 — نظرة عامة: عرض الصفوف، الإحصاءات، وعدد الوظائف حسب المسمى.
- صفحة 2 — المعالجة المسبقة: تطبيق تنظيف النصوص، إزالة stopwords، وlemmatization.
- صفحة 3 — استخراج المهارات: طرق `rule`, `ml`, `hybrid` مع تنزيل النتائج.
- صفحة 4 — التلخيص: TextRank أو Transformer (اختياري) لتوليد ملخصات.
- صفحة 5 — التصور: سحابة كلمات، مخطط المسميات، ومخطط تكرار المهارات.
